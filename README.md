# Aprenda+ — versão visual profissional

## Estrutura
- `index.html`: estrutura da página
- `css/style.css`: identidade visual e responsividade
- `js/script.js`: pesquisa, filtros e interação dos botões

## Publicar no GitHub Pages
1. Faça backup dos arquivos atuais.
2. Copie os arquivos e pastas deste pacote para a raiz do repositório.
3. Faça commit e push.
4. Em Settings → Pages, confirme a origem de publicação configurada.
5. Abra o site e atualize com Ctrl+F5.

As imagens são carregadas de URLs do Unsplash e as fontes do Google Fonts; precisam de conexão à internet. Os botões de interesse são demonstrativos e não armazenam inscrições. Os depoimentos são exemplos de layout, não avaliações reais.
